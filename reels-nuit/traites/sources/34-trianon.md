# 34 — Trianon, 1920 : sources (fait → URL)

- Traité signé le 4 juin 1920 au Grand Trianon, à Versailles ; ratifié par la Hongrie le 16 novembre 1920, en vigueur le 26 juillet 1921 → https://fr.wikipedia.org/wiki/Traité_de_Trianon ; https://en.wikipedia.org/wiki/Treaty_of_Trianon
- Signataires : la Hongrie (Ágost Benárd, Alfréd Drasche-Lázár) face aux Alliés et associés, dont France, Royaume-Uni, Roumanie, Tchécoslovaquie, royaume SCS → https://en.wikipedia.org/wiki/Treaty_of_Trianon
- Superficie : 282 870 km² sans la Croatie-Slavonie (environ 325 000 km² avec) → 93 000 km² environ après le traité ; perte d'environ 67 % sans la Croatie, environ 71-72 % Croatie comprise → https://en.wikipedia.org/wiki/Treaty_of_Trianon (Nitti, « 67 %, 71 % including Croatia ») ; https://fr.wikipedia.org/wiki/Traité_de_Trianon
  - NB : le 72 % de la consigne est le chiffre Croatie-Slavonie COMPRISE (pas « hors Croatie », qui donne 67 %). Le brief dit « environ 72 % » avec la mention « Croatie comprise » à l'écran ; la voix dit « plus des deux tiers », vrai dans les deux calculs.
- Population : environ 21 millions → environ 7,6 millions, soit une perte d'environ 64 % (Croatie comprise ; 28 % du sol et 36 % des habitants conservés) → https://en.wikipedia.org/wiki/Treaty_of_Trianon ; https://fr.wikipedia.org/wiki/Traité_de_Trianon
- Environ 3,3 millions de Hongrois (langue maternelle, recensement de 1910) dans les territoires cédés, soit environ un magyarophone sur trois (d'autres sources : 3,4 millions) → https://fr.wikipedia.org/wiki/Traité_de_Trianon ; https://en.wikipedia.org/wiki/Treaty_of_Trianon
- Recensement de 1910 (hors Croatie-Slavonie) : hongrois environ 54 %, roumain 16 %, slovaque 10,5 %, allemand 10,4 %, serbe et ruthène 2,5 % chacun ; Croatie comprise, les Hongrois sont un peu moins de la moitié → voix : « environ la moitié » → https://en.wikipedia.org/wiki/Ethnic_and_religious_composition_of_Austria-Hungary
- Partage (km², environ) : Roumanie 103 093 (Transylvanie, Partium/Crișana, sud du Maramureș, Banat oriental) ; royaume SCS 63 092 (Croatie-Slavonie, Bácska, Banat occidental, Prekmurje/Muravidék) ; Tchécoslovaquie 61 633 (Slovaquie, Ruthénie subcarpatique) ; Autriche 3 962 (Burgenland) ; Pologne 580 (parties d'Árva et de Szepes, non coloriées) ; Fiume : État libre, puis Italie (non colorié) → https://fr.wikipedia.org/wiki/Traité_de_Trianon
- Royaume de Hongrie = une des deux moitiés de l'Autriche-Hongrie (compromis de 1867), Croatie-Slavonie autonome dans le royaume → https://fr.wikipedia.org/wiki/Autriche-Hongrie ; https://fr.wikipedia.org/wiki/Royaume_de_Croatie-Slavonie
- Novembre 1918 : défaite et dislocation de l'Autriche-Hongrie ; troupes roumaines (Transylvanie), tchécoslovaques (Slovaquie) et serbes (Voïvodine) entrent dans le royaume en 1918-1919 → https://en.wikipedia.org/wiki/Treaty_of_Trianon (occupation sous le gouvernement Károlyi) ; https://fr.wikipedia.org/wiki/Guerre_hungaro-roumaine
- 1919 : frontières fixées par les vainqueurs à la conférence de la paix de Paris ; délégation hongroise (Apponyi) reçue en janvier 1920 → https://fr.wikipedia.org/wiki/Conférence_de_paix_de_Paris_(1919) ; https://mki.gov.hu/en/hirek-en/evfortulok-en/apponyi-ekkor-en
- Aujourd'hui : la frontière de Trianon reste celle de la Hongrie, à trois villages près cédés à la Tchécoslovaquie en 1947 (tête de pont de Bratislava) ; les anciens territoires se trouvent dans ses sept voisins actuels (Slovaquie, Ukraine, Roumanie, Serbie, Croatie, Slovénie, Autriche) → https://en.wikipedia.org/wiki/Paris_Peace_Treaties,_1947 ; https://en.wikipedia.org/wiki/Borders_of_Hungary
