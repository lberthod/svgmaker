# 34 Pays basque / euskara

- Euskara = isolat, sans parenté prouvée, antérieur aux langues indo-européennes (hypothèse dominante, « sans doute ») : https://en.wikipedia.org/wiki/Basque_language
- Locuteurs : environ 806 000 (2021, 16 ans et plus, sept provinces) ; part 22,3 % (1991), 27,0 % (2011), 30,6 % (2021) : https://en.wikipedia.org/wiki/Basque_language (enquête sociolinguistique)
- Franco : euskara réprimé (enseignement, édition, usage public) 1939-1975 : https://en.wikipedia.org/wiki/Basque_language
- Statut : co-officiel dans la communauté autonome ; en Navarre seulement dans la zone basquophone ; aucun statut officiel en France : https://en.wikipedia.org/wiki/Basque_language
- Euskara batua : Euskaltzaindia, Arantzazu, 1968 (de mémoire, à vérifier) : https://en.wikipedia.org/wiki/Basque_language#Standard_Basque
- Statut de Guernica 1979 (de mémoire) : https://fr.wikipedia.org/wiki/Statut_d%27autonomie_du_Pays_basque
- Guernica 26 avril 1937 (Légion Condor, aviation italienne) (de mémoire) : https://fr.wikipedia.org/wiki/Bombardement_de_Guernica
- Pampelune fondée par Pompée vers 74 av. J.-C. ; royaume de Pampelune 824 ; Haute-Navarre conquise 1512 ; Basse-Navarre unie à la France 1620 (de mémoire) : https://fr.wikipedia.org/wiki/Royaume_de_Navarre
- Fueros : France 1789-90 ; Espagne loi de 1839 puis abolition 1876 (de mémoire) : https://fr.wikipedia.org/wiki/Fueros
- Sept provinces : Araba, Bizkaia, Gipuzkoa, Navarre, Labourd, Basse-Navarre, Soule : https://fr.wikipedia.org/wiki/Pays_basque

Limites : la région carte « Pyrénées-Atlantiques » couvre aussi le Béarn (non basque) ; la zone vasconne antique est approximée par les sept provinces.
